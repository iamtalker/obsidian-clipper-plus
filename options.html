Obsidian Clipper Plus — 설정

옵시디언 → 설정 → 커뮤니티 플러그인 → "Local REST API with MCP" → Enable Non-encrypted (HTTP) Server를 켜세요.
팝업이 이 방법(그리고 아래 기본 폴더)으로 미리 선택된 채 열려서, 아이콘을 누르고 Clip만 누르면 저장됩니다.
볼트 루트 기준 경로입니다. 비워 두면 볼트 루트에 저장하고, 폴더가 없으면 자동으로 만듭니다.
비워 두면 볼트 루트입니다. ./로 시작하면 노트 옆에 저장합니다: ./ = 노트가 있는 폴더, ./attachments = 그 안의 하위 폴더(옵시디언 자체 설정과 같은 방식). 옵시디언의 첨부 파일 설정 가져오기
