# Obsidian Clipper Plus

웹페이지를 옵시디언(Obsidian) 볼트에 마크다운 노트로 저장하는 크롬 확장(Manifest V3)입니다. **이미지까지 볼트 안에 파일로 저장**하기 때문에, 원본 사이트에서 글이나 이미지가 사라져도 노트는 그대로 남아요.

> 이 프로젝트는 조플린용 웹 클리퍼 **[Joplin Clipper Plus](https://github.com/iamtalker/joplin-clipper-plus)를 포크해서 옵시디언용으로 바꾼 것**입니다. 페이지 본문 추출, 한국 커뮤니티 사이트 대응, CORS로 막힌 이미지 캡처, 웹툰 모드 같은 핵심 코드는 원본과 공유하고(원본 레포에서 동기화), 저장하는 부분만 옵시디언용으로 새로 만들었습니다. 두 레포는 같은 버전 번호로 함께 업데이트됩니다.

옵시디언 공식 확장이 아닌 비공식 확장입니다.

## 기능
- 📄 **Article** — Readability로 본문만 추출해 마크다운으로 저장 (광고/사이드바 제거)
- ✂️ **Selection** — 드래그로 선택한 영역만 저장. 선택 전에 모드를 먼저 누르면 페이지 우상단에 저장/취소 툴바가 떠서, 그 상태로 드래그 → 💾 Save
- 🔖 **Bookmark** — 링크 + 설명만 가볍게 저장
- 📜 **Webtoon** — 게시글의 큰 이미지를 순서대로 전부 원본 파일로 저장
- 저장 폴더 선택, 태그 입력, 제목 수정 지원
- 노트 맨 위에 속성(frontmatter)으로 `title`, `source`(원본 주소), `clipped`(저장 시각), `tags` 기록
- 이미지는 첨부 폴더(기본 `Clippings/attachments`)에 파일로 저장되고, 노트에는 `![[파일명]]`으로 들어감
- 같은 제목의 노트가 이미 있으면 덮어쓰지 않고 `제목 (2).md`처럼 번호를 붙임

조플린 버전의 **Full Page** 모드(전체 HTML 스냅샷)는 옵시디언이 통째 HTML을 잘 보여주지 못해서 빠져 있어요.

## 설치 방법

### 1. 옵시디언에 Local REST API 플러그인 설치
옵시디언에는 외부 프로그램이 노트를 저장할 수 있는 통로가 기본으로 없어서, 이 플러그인이 그 통로를 열어줍니다. 내 컴퓨터 안(`127.0.0.1`)에서만 접속됩니다.
1. 옵시디언 **설정 → 커뮤니티 플러그인** → "제한 모드 끄기"
2. **탐색**에서 **Local REST API with MCP**(제작자: coddingtonbear) 검색 → 설치 → 활성화
3. 플러그인 설정에서 **Enable Non-encrypted (HTTP) Server** 켜기
   - 기본 HTTPS 서버는 자체 서명 인증서를 써서 크롬 확장에서 바로 접속할 수 없어요. 통신이 내 컴퓨터 밖으로 나가지 않으니 HTTP로 충분해요.
4. 같은 화면의 **API Key** 복사

### 2. 확장 프로그램 설치
1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더를 선택

### 3. API 키 등록
1. 확장 아이콘 클릭 → 팝업 상단의 "settings" 클릭
2. 포트(기본 27123)와 1단계에서 복사한 API 키 입력
3. 필요하면 기본 저장 폴더, 첨부 폴더, "저장 후 옵시디언에서 열기" 설정 → **Save**
4. **Test connection**으로 연결 확인 (옵시디언이 켜져 있어야 함)

## 사용법
1. 클리핑하고 싶은 페이지로 이동
2. 확장 아이콘 클릭
3. 캡처 모드 선택 (Article / Selection / Bookmark / Webtoon)
4. 제목 수정, 폴더 선택, 태그 입력 (선택)
5. **Clip to Obsidian** 클릭

## 알려진 제한사항
- 옵시디언 앱이 켜져 있고, Local REST API 플러그인의 HTTP 서버가 켜져 있어야 저장됩니다. 저장은 **지금 열려 있는 볼트**에 됩니다.
- 폴더 선택 목록에는 파일이 하나라도 들어 있는 폴더만 보입니다(플러그인 API가 빈 폴더는 알려주지 않음). 새 폴더는 설정의 기본 폴더에 이름을 적으면 자동으로 만들어져요.
- 노트를 지워도 첨부 이미지는 자동으로 지워지지 않습니다(옵시디언 기본 동작). 필요하면 첨부파일 정리 플러그인을 쓰세요.
- 이미지 캡처 방식, 사이트별 본문 지정(`SITE_CONTENT_SELECTORS` 등), 로컬 파일/크롬 내부 페이지 제한은 원본과 같아요. 자세한 내용은 [원본 README](https://github.com/iamtalker/joplin-clipper-plus#알려진-제한사항)를 참고하세요.

## 개발 메모
- 공유 파일(`content.js`, `core.js`, `toolbar.js`, `popup.js`, `lib/`)은 원본 레포가 기준입니다. 여기서 직접 고치지 말고 원본에서 고친 뒤 원본의 `scripts/sync-to-obsidian.sh`로 복사해 오세요.
- 이 레포에만 있는 파일: `background.js`(옵시디언 저장), `popup.html`, `options.*`, `manifest.json`, 문서.

## 변경 이력
- **0.36.1** — 첫 버전. Joplin Clipper Plus 0.36.1을 포크해서 옵시디언용으로 전환. 원본의 `background.js`를 공통 부분(`core.js`: 페이지 주입, 이미지 캡처 폴백, 메시지 처리)과 저장 부분으로 나누고, 저장 부분을 Local REST API 플러그인을 쓰는 옵시디언용으로 새로 작성. 조플린은 본문에 넣은 이미지를 알아서 첨부파일로 바꿔주지만 옵시디언은 받은 글자를 그대로 저장하기 때문에, 본문의 이미지를 하나씩 첨부 폴더에 파일로 올리고 `![[파일명]]`으로 바꿔 넣음(같은 이미지가 여러 번 나오면 한 번만 저장). 조플린의 노트북 → 볼트 폴더, 태그 → frontmatter `tags`로 대응. 파일 이름에 못 쓰는 문자 정리, 같은 이름 노트/이미지는 덮어쓰지 않고 번호 붙임. Full Page 모드는 제외. 실제 크롬+실제 옵시디언 볼트에서 Article / Webtoon / Bookmark / Selection 툴바 저장, 한글 제목, 태그, 이미지 원본 그대로 저장(바이트 단위 동일), 같은 초에 여러 번 저장해도 이미지가 겹쳐 쓰이지 않음까지 확인.
