# Obsidian Clipper Plus

웹페이지를 옵시디언(Obsidian) 볼트에 마크다운 노트로 저장하는 크롬 확장(Manifest V3)입니다. **이미지까지 볼트 안에 파일로 저장**하기 때문에, 원본 사이트에서 글이나 이미지가 사라져도 노트는 그대로 남아요.

> 이 프로젝트는 조플린용 웹 클리퍼 **[Joplin Clipper Plus](https://github.com/iamtalker/joplin-clipper-plus)를 포크해서 옵시디언용으로 바꾼 것**입니다. 페이지 본문 추출, 한국 커뮤니티 사이트 대응, CORS로 막힌 이미지 캡처, 웹툰 모드 같은 핵심 코드는 원본과 공유하고(원본 레포에서 동기화), 저장하는 부분만 옵시디언용으로 새로 만들었습니다. 공유 코드가 바뀌면 두 확장이 함께 업데이트되고, 한쪽 전용 변경은 그쪽 버전만 올라갑니다.

옵시디언 공식 확장이 아닌 비공식 확장입니다.

## 기능
- 📄 **Article** — Readability로 본문만 추출해 마크다운으로 저장 (광고/사이드바 제거)
- ✂️ **Selection** — 드래그로 선택한 영역만 저장. 선택 전에 모드를 먼저 누르면 페이지 우상단에 저장/취소 툴바가 떠서, 그 상태로 드래그 → 💾 Save
- 🖼 **Full Page** — 페이지를 모양 그대로(스타일, 이미지 포함) HTML 파일 하나로 보관. 노트에는 그 파일을 여는 링크가 들어감
- 🔖 **Bookmark** — 링크 + 설명만 가볍게 저장
- 📜 **Webtoon** — 게시글의 큰 이미지를 순서대로 전부 원본 파일로 저장
- 저장 폴더 선택, 태그 입력, 제목 수정 지원
- 노트 맨 위에 속성(frontmatter)으로 `title`, `source`(원본 주소), `clipped`(저장 시각), `tags` 기록
- 이미지는 첨부 폴더(기본 `Clippings/attachments`)에 파일로 저장되고, 노트에는 `![[파일명]]`으로 들어감
- 같은 제목의 노트가 이미 있으면 덮어쓰지 않고 `제목 (2).md`처럼 번호를 붙임

**Full Page**는 조플린과 저장 방식이 달라요. 조플린은 HTML 노트를 지원해서 노트 안에 페이지가 그대로 보이지만, 옵시디언 노트는 마크다운뿐이고 HTML을 넣으면 스타일이 지워져서 모양이 깨져요. 그래서 페이지를 이미지까지 안에 넣은 `.html` 파일 하나로 첨부 폴더에 저장하고, 노트에는 `[[파일.html]]` 링크를 넣어요. 링크를 누르면 기본 브라우저에서 원래 모양대로 열려요(원본 사이트가 사라져도 열림).

## 설치 방법

### 1. 옵시디언에 Local REST API 플러그인 설치
옵시디언에는 외부 프로그램이 노트를 저장할 수 있는 통로가 기본으로 없어서, 이 플러그인이 그 통로를 열어줍니다. 내 컴퓨터 안(`127.0.0.1`)에서만 접속됩니다.
1. 옵시디언 **설정 → 커뮤니티 플러그인** → "제한 모드 끄기"
2. **탐색**에서 **Local REST API with MCP**(제작자: coddingtonbear) 검색 → 설치 → 활성화
3. 플러그인 설정에서 **Enable Non-encrypted (HTTP) Server** 켜기
   - 기본 HTTPS 서버는 자체 서명 인증서를 써서 크롬 확장에서 바로 접속할 수 없어요. 통신이 내 컴퓨터 밖으로 나가지 않으니 HTTP로 충분해요.
4. 같은 화면의 **API Key** 복사

### 2. 확장 프로그램 설치
1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더를 선택

### 3. API 키 등록
1. 확장 아이콘 클릭 → 팝업 상단의 "settings" 클릭
2. 포트(기본 27123)와 1단계에서 복사한 API 키 입력
3. 필요하면 기본 저장 폴더, 첨부 폴더, "저장 후 옵시디언에서 열기" 설정 → **Save**
   - 첨부 폴더를 `./`로 시작하면 노트가 저장되는 폴더 기준이에요(`./` = 노트와 같은 폴더, `./attachments` = 그 아래 폴더). 비워 두면 볼트 최상위.
   - **Use Obsidian's attachment setting**을 누르면 옵시디언의 "새 첨부 파일 기본 위치" 설정을 읽어서 채워 줘요.
4. **Test connection**으로 연결 확인 (옵시디언이 켜져 있어야 함)

## 사용법
1. 클리핑하고 싶은 페이지로 이동
2. 확장 아이콘 클릭
3. 캡처 모드 선택 (Article / Selection / Full Page / Bookmark / Webtoon)
4. 제목 수정, 폴더 선택, 태그 입력 (선택)
5. **Clip to Obsidian** 클릭

## 알려진 제한사항
- Full Page로 저장한 `.html` 파일은 옵시디언 안에서는 바로 보이지 않고, 노트의 링크를 누르면 기본 브라우저로 열립니다. 옵시디언 안에서 보고 싶으면 HTML 뷰어 플러그인(예: HTML Reader)을 설치하세요.
- 옵시디언 앱이 켜져 있고, Local REST API 플러그인의 HTTP 서버가 켜져 있어야 저장됩니다. 저장은 **지금 열려 있는 볼트**에 됩니다.
- 폴더 선택 목록에는 파일이 하나라도 들어 있는 폴더만 보입니다(플러그인 API가 빈 폴더는 알려주지 않음). 새 폴더는 설정의 기본 폴더에 이름을 적으면 자동으로 만들어져요.
- 노트를 지워도 첨부 이미지는 자동으로 지워지지 않습니다(옵시디언 기본 동작). 필요하면 첨부파일 정리 플러그인을 쓰세요.
- 이미지 캡처 방식, 사이트별 본문 지정(`SITE_CONTENT_SELECTORS` 등), 로컬 파일/크롬 내부 페이지 제한은 원본과 같아요. 자세한 내용은 [원본 README](https://github.com/iamtalker/joplin-clipper-plus#알려진-제한사항)를 참고하세요.

## 개발 메모
- 공유 파일(`content.js`, `core.js`, `toolbar.js`, `popup.js`, `lib/`)은 원본 레포가 기준입니다. 여기서 직접 고치지 말고 원본에서 고친 뒤 원본의 `scripts/sync-to-obsidian.sh`로 복사해 오세요.
- 이 레포에만 있는 파일: `background.js`(옵시디언 저장), `popup.html`, `options.*`, `manifest.json`, 문서.
- 이어서 작업할 때는 [HANDOFF.md](HANDOFF.md)부터 읽으세요.

## 변경 이력
- **0.38.1** — **표가 깨지던 문제 수정**(사용자 제보: 영어 위키백과 Obsidian 문서의 정보 상자). ① 공유 코드(조플린 0.38.0과 같음): 칸 안의 줄바꿈 때문에 표 행이 쪼개지던 문제(`<br>`로 이어 붙임), 제목 칸이 표 전체 폭이라 값 칸이 안 보이던 문제(칸 수 맞춤), 머리행 없는 단순한 표가 HTML로 남아 안의 사진이 안 보이던 문제(마크다운 표로 변환). ② 옵시디언 전용: 0.37.0에서 HTML 안의 사진을 보이게 하려고 앞뒤에 빈 줄을 넣었는데, 표 칸이나 링크 안의 작은 아이콘에도 넣어서 표와 링크를 끊어 놓았음. 이제 문단이 `<table>`·`<div>` 같은 블록 태그로 시작하는 진짜 HTML 블록일 때만 빈 줄을 넣고, 마크다운 표 안에서는 `![[파일\|너비]]`처럼 `|`를 이스케이프(안 하면 칸 구분자로 읽힘), 그 밖에는 그대로 인라인으로 둠(나무위키의 한 줄에 붙은 아이콘들이 한 줄씩 쪼개지던 것도 해결). 영어/한국어 위키백과, 나무위키, 휴먼유니브와 기존 커뮤니티 사이트들로 확인.
- **0.38.0** — 옵시디언 전용 개선(조플린은 변경 없음). ① 첨부 폴더를 옵시디언 자체 설정과 같은 방식으로 지정 가능: `./`로 시작하면 노트가 저장되는 폴더 기준(`./` = 노트와 같은 폴더, `./attachments` = 그 아래). 예전엔 고정 경로만 돼서, 옵시디언에서 "현재 파일과 같은 폴더"를 쓰는 사람은 클립한 이미지만 다른 곳에 모였음. ② 설정 화면에 "Use Obsidian's attachment setting" 버튼 추가 — 볼트의 `.obsidian/app.json`(`attachmentFolderPath`)을 읽어 칸을 채움. ③ 설정 화면의 API 키가 그대로 보이던 것을 비밀번호처럼 가림(화면 공유나 스크린샷에 키가 찍힐 수 있었음). ④ 첨부 폴더 칸을 비우면 볼트 최상위라는 설명 추가(흐린 예시 글자 `Clippings/attachments` 때문에 그게 적용되는 것처럼 보였음). 실제 크롬+볼트에서 `./att`, `./`, 일반 경로 세 가지 저장 위치와 버튼 동작 확인.
- **0.37.0** — **Full Page 모드 추가**(사용자 요청: 조플린 버전과 기능을 똑같이 맞추고 싶음). 0.36.1에서는 옵시디언이 HTML 노트를 지원하지 않고, 마크다운에 넣은 HTML은 스타일이 지워져 모양이 깨지기 때문에 이 모드를 뺐었음. 해결: 공유 코드가 이미 만들어 주는 전체 페이지 HTML(스크립트 제거, 이미지는 data: URL로 안에 포함)을 첨부 폴더에 `YYYYMMDD-HHMMSS-제목.html` 파일 하나로 저장하고(이름이 겹치면 번호를 붙임), 노트에는 frontmatter + `[[파일.html|🖼 저장된 전체 페이지 열기]]` 링크 + 원본 주소를 넣음. 팝업 버튼 배치도 조플린과 같게 맞춤. 실제 크롬+실제 볼트에서 저장, 스타일·이미지가 살아 있는 HTML, 같은 제목 두 번 저장 시 노트 `(2)`와 HTML 파일이 따로 생기는 것까지 확인. 함께 실제 사이트를 돌며 점검해서 고친 것: ① 사진 설명에 `[뉴욕=AP/뉴시스]`처럼 대괄호가 있으면(마크다운에서 `[ ]`로 바뀜) 이미지 추출 정규식이 거기서 끊겨, 사진이 파일로 빠지지 않고 수십 KB짜리 data: 덩어리로 노트에 남던 문제 수정(Daum 뉴스에서 발견). ② 표 같은 HTML 안에 있던 사진(휴먼유니브 MP4 첨부, 위키백과 정보 상자)은 옵시디언이 HTML 블록 안의 `![[ ]]`를 그리지 않아 안 보이던 문제 — 앞뒤에 빈 줄을 넣어 HTML 밖으로 빼고 원래 너비는 `![[파일|너비]]`로 유지. ③ 공유 코드 수정(조플린 0.37.0과 같음): Daum 뉴스 지원, 쿠키를 붙이면 거절하는 이미지 서버(Daum, 오늘의유머) 대응, 아카라이브 429 재시도, 더쿠 광고 추천 검색어 제거, 디시 닉네임 아이콘 제거. 디시(PC/모바일), 클리앙, 뽐뿌, 오늘의유머, 휴먼유니브, SLR, 이토랜드, 인벤, 더쿠, 82쿡, 아카, 루리웹, 네이버 블로그, 나무위키, 위키백과, Daum의 사진 있는 글을 실제로 저장해서 확인.
- **0.36.1** — 첫 버전. Joplin Clipper Plus 0.36.1을 포크해서 옵시디언용으로 전환. 원본의 `background.js`를 공통 부분(`core.js`: 페이지 주입, 이미지 캡처 폴백, 메시지 처리)과 저장 부분으로 나누고, 저장 부분을 Local REST API 플러그인을 쓰는 옵시디언용으로 새로 작성. 조플린은 본문에 넣은 이미지를 알아서 첨부파일로 바꿔주지만 옵시디언은 받은 글자를 그대로 저장하기 때문에, 본문의 이미지를 하나씩 첨부 폴더에 파일로 올리고 `![[파일명]]`으로 바꿔 넣음(같은 이미지가 여러 번 나오면 한 번만 저장). 조플린의 노트북 → 볼트 폴더, 태그 → frontmatter `tags`로 대응. 파일 이름에 못 쓰는 문자 정리, 같은 이름 노트/이미지는 덮어쓰지 않고 번호 붙임. Full Page 모드는 제외. 실제 크롬+실제 옵시디언 볼트에서 Article / Webtoon / Bookmark / Selection 툴바 저장, 한글 제목, 태그, 이미지 원본 그대로 저장(바이트 단위 동일), 같은 초에 여러 번 저장해도 이미지가 겹쳐 쓰이지 않음까지 확인.
